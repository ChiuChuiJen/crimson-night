# 血夜：吸血鬼之影（Crimson Night）

2.5D 吸血鬼動作遊戲，純 HTML5 Canvas，電腦與手機瀏覽器都能玩。

**▶ 線上遊玩：** https://chiuchuijen.github.io/crimson-night/

目前版本：**V1.5.0**（[更新紀錄](CHANGELOG.md)）

## 特色
- 日夜輪替：白天陽光會灼燒你，躲進樹林、房屋或城堡的陰影
- 迷霧地圖、小地圖與大地圖
- 吸人類的血回復生命，不同人類給予不同 buff
- 普攻三連擊與 4 個技能（血矢、蝙蝠群、霧化、血月新星）
- 屬性、天賦、背包裝備（7 個欄位、多種武器與防具）、10 種神器被動技能、商人與金幣
- 8 章主線任務、每日懸賞、4 種 Boss
- 4 座地下城副本（3 層隨機地圖、頭目、每日通關獎勵）
- 奧天塔：無限樓層迷宮挑戰、排行榜、傳送卷
- 天氣系統、棺材沉睡、森林樵夫、獵魔人突襲城堡
- 37 個成就與「血統傳承」永久加成
- 城堡倉庫（可擴充）、背包分類篩選、依武器變化的攻擊動畫
- 存檔 / 讀檔（自動存檔、快速存檔、匯出匯入）
- 程序合成的背景音樂與音效

## 操作
| | 電腦 | 手機 |
|---|---|---|
| 移動 | WASD / 方向鍵 | 左半螢幕虛擬搖桿 |
| 攻擊 | 滑鼠左鍵 / 空白鍵 | 🗡 按鈕（自動瞄準） |
| 吸血 / 開寶箱 / 對話 | E | 🦷 按鈕 |
| 技能 | 1~4（右鍵 = 血矢） | 技能按鈕 |
| 血瓶 | Q | 🧪 按鈕 |
| 背包 / 屬性 / 天賦 | B / C / T | 右上 🎒 |
| 任務 / 成就 / 地圖 | L / K / M | 右上 📜 🏆 🗺 |
| 快速存檔 / 讀檔 | F5 / F9 | 暫停選單 |

## 本機遊玩
雙擊 `啟動遊戲.bat`，會啟動本機伺服器並開啟瀏覽器；同一個 Wi-Fi 的手機可用畫面上顯示的網址遊玩。
